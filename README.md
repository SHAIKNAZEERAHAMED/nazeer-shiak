## Featured projects

### Aegis V2 Privacy Pipeline
Research MVP for privacy-preserving video capture using FastAPI, OpenCV, PyTorch and FaceNet.

Source: https://github.com/SHAIKNAZEERAHAMED/aegis-v2-privacy-pipeline

### GraphDB Benchmark
Reproducible benchmark comparing CognoDB Cloud, Neo4j AuraDB Free, Memgraph Cloud, FalkorDB Cloud and ArangoDB Oasis on a SNAP soc-Pokec graph workload.

Source: https://github.com/SHAIKNAZEERAHAMED/graphdb-benchmark

### LoopedCSS
Full-stack social platform built with Next.js, React, TypeScript and Firebase, with feed, search, notifications, profiles, moderation and real-time functionality.

Source: https://github.com/SHAIKNAZEERAHAMED/loopedcss

### Yernstudios
React + TypeScript agency website using Vite, Tailwind CSS, shadcn/ui and Supabase.

Source: https://github.com/SHAIKNAZEERAHAMED/yernstudios

## Development

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

Lint:

```bash
npm run lint
```

The portfolio contains both engineering and editing work. Project descriptions and links are kept aligned with currently verified repositories; unfinished or unsupported projects are not presented as active portfolio claims.
